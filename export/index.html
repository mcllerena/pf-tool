Exporting results

Source: exporter.py (ExportSolution).

Usage

Section titled “Usage”

Solve the case, then pass the solver to ExportSolution:

The same call works with OptimizationPowerFlow. Both example scripts in examples/ end with this step and write to examples/results/.

Argument Default Meaning
solver — A solver on which solve() was called
output_path — Workbook file; missing folders are created
format "excel" Only Excel (.xlsx) is supported
export True False builds the tables (.sheets) without writing the file

How the values are obtained

Section titled “How the values are obtained”

The solvers work on the reduced network. After solving, ReducedCase.write_back copies every solved control back to the original case. That covers bus types, switched-shunt steps, SVC outputs, LCC set-points, and transformer taps and phase shifts. The exporter then works on the original buses and branches with the expanded voltages.

Branch flows. For every branch that was not contracted, the exporter uses the π-model terminal powers SfS_fSf​ and StS_tSt​ with the final tap and phase.

Collapsed links. These are switches, bypassed CSCs, and other branches at or below the zero impedance threshold. They cannot be evaluated from voltages, because both ends are the same electrical node. In each reduced node, the exporter solves the series flows from Kirchhoff’s current law at the member buses:

∑k collapsedAmk fk=Smlocal−Smshunt−∑k not collapsedSm,k−∑k collapsedSm,kcharging\sum_{k\,\text{collapsed}} A_{mk}\,f_k = S^{local}_m - S^{shunt}_m - \sum_{k\,\text{not collapsed}} S_{m,k} - \sum_{k\,\text{collapsed}} S^{charging}_{m,k}kcollapsed∑​Amk​fk​=Smlocal​−Smshunt​−knot collapsed∑​Sm,k​−kcollapsed∑​Sm,kcharging​

The system is solved with least squares, which gives the minimum-norm solution for meshed groups. Each link keeps its line charging, −j b2∣V∣2-j\,\tfrac{b}{2}|V|^2−j2b​∣V∣2 per end. The test case CASO01 has 1,222 collapsed links. In the exported solution, every bus balances to within 3×10−53\times10^{-5}3×10−5 MVA, and the system active-power balance closes to 10−610^{-6}10−6 MW.

Generator outputs. The solver balances power per reduced node, so the machine output of a node is:

Pnodem=∑i∈node(Picalc−Pihvdc+Pil),Qnodem=∑i∈node(Qicalc−Qisvc−Qihvdc+Qil).P^{m}_{node} = \sum_{i\in node}\big(P^{calc}_i - P^{hvdc}_i + P^{l}_i\big),\qquad Q^{m}_{node} = \sum_{i\in node}\big(Q^{calc}_i - Q^{svc}_i - Q^{hvdc}_i + Q^{l}_i\big).Pnodem​=i∈node∑​(Picalc​−Pihvdc​+Pil​),Qnodem​=i∈node∑​(Qicalc​−Qisvc​−Qihvdc​+Qil​).

It is allocated to the node’s buses in three ways:

  • Active power: PV generators keep their scheduled PgP_gPg​. A reference node gives the remainder to its Tb = 2 buses.
  • Reactive power at PV and reference nodes: the output is shared among the voltage-controlling generators in proportion to their reactive ranges Qgm − Qgn.
  • Reactive power at PQ nodes: each bus keeps its scheduled QgQ_gQg​.

HVDC and SVC terms are reported separately from machine generation and DBAR load:

  • Rectifier: P and Q are load.
  • Inverter: P is a source, and Q is load.
  • SVC: the output is listed in its own column.

The Loads sheet therefore shows the DBAR loads only.
