Zero impedance threshold

Section titled “Zero impedance threshold”

Links with very small impedance make the Jacobian ill-conditioned. These include breakers modeled as lines, bypassed CSCs, and ideal ties. Any branch with ∣r+jx∣≤2×10−4|r + jx| \le 2\times10^{-4}∣r+jx∣≤2×10−4 pu is therefore contracted. Its two terminals become one electrical node.

Contraction respects ideal transformer ratios. Union-find tracks, for every bus iii, its group representative and a complex scale sis_isi​ such that:

Vi=si Vrep(i).V_i = s_i\,V_{\text{rep}(i)} .Vi​=si​Vrep(i)​.

Contracting a branch with ratio N=aejφN = a e^{j\varphi}N=aejφ between fff and ttt imposes sf=N sts_f = N\,s_tsf​=Nst​. If a loop of contracted branches implies inconsistent ratios, that branch is not merged.

Island references

Section titled “Island references”

The solver finds connected components of YbusY_{bus}Ybus​. Every island without a reference bus receives one: the PV bus with the largest scheduled active generation, or any bus if the island has no PV bus. Isolated systems therefore keep a well-defined angle reference and slack.

Initial point

Section titled “Initial point”

Both solvers start from the stored voltages DBAR.V and A0, which are ANAREDE’s solution.

  1. Tap reconciliation fixes transformer settings that contradict those voltages; see Tap and phase controls.
  2. Newton angle warm start: before Newton starts, a short active-power-only angle correction may adjust the angles. It runs a few decoupled PPP–θ\thetaθ Newton steps from both the stored angles and flat angles, and keeps the start with the smaller mismatch.
