Static VAR compensators

Source: models/svc.py, newton_raphson.py, and optimization.py.

Data

Section titled “Data”

Each in-service DCER record has these parameters:

Symbol From Meaning
ddd Bus Terminal (device) bus
ccc Bctrl Controlled bus; the device bus is used if Bctrl is missing
VrefV^{ref}Vref DBAR.V of ccc Voltage reference
mmm Incl/100 Droop slope (pu V per pu Q)
q0q^0q0 Qg/BASE Initial output; it is also added to the bus Qg
Qmin⁡,Qmax⁡Q_{\min}, Q_{\max}Qmin​,Qmax​ Qgn, Qgm /BASE Inductive and capacitive capability at 1 pu
mode Ctrl P reactive-power droop, I current droop

An SVC is active when its device bus is PQ. If the bus is PV or the reference bus, that bus already fixes the voltage.

Region logic

Section titled “Region logic”

The two solvers use the same region logic at different times.

Newton checks the region in every iteration (refresh_svc_limits). From the controlled voltage, it computes the output that the control law asks for:

qreq=Vref−κc∣Vc∣m(mode I: × κd∣Vd∣)q^{req} = \frac{V^{ref} - \kappa_c|V_c|}{m}\quad(\text{mode } I:\ \times\,\kappa_d|V_d|)qreq=mVref−κc​∣Vc​∣​(mode I: ×κd​∣Vd​∣)

It then clamps the SVC to its capability. The Jacobian row switches between the control law and the limit equation.

The optimization model fixes each region for an NLP solve. After the solve, update_svc_regions changes a region in these cases:

  • A regulating SVC whose output left its capability, or sits on a limit while qreqq^{req}qreq points beyond it, saturates.
  • A saturated SVC returns to regulation when qreqq^{req}qreq falls back inside its capability. It never jumps directly to the opposite limit, which prevents ±1 cycling.

Solved outputs

Section titled “Solved outputs”

After a converged Newton pass, the solved outputs are written back to case.svcs, and the bus generation is updated accordingly. The next pass and an optimization warm start therefore begin from the solved SVC state.
