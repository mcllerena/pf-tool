Branch model

Section titled “Branch model”

Every in-service DLIN record is one branch kkk from bus fff (I) to bus ttt (J). The model has four parts:

  • Series admittance: yk=1/(rk+jxk)y_k = 1/(r_k + j x_k)yk​=1/(rk​+jxk​), where rk=R/100r_k = R/100rk​=R/100 and xk=X/100x_k = X/100xk​=X/100 pu.
  • Line charging: total bk=Bshl/Sbaseb_k = \text{Bshl}/S_{base}bk​=Bshl/Sbase​, with jbk/2j b_k/2jbk​/2 at each end.
  • Ideal transformer at the from side: complex ratio Nk=akejφkN_k = a_k e^{j\varphi_k}Nk​=ak​ejφk​.
    • aka_kak​ is Tap; a value of 0 or blank means 1.
    • φk=− Psh⋅π/180\varphi_k = -\,\text{Psh}\cdot\pi/180φk​=−Psh⋅π/180.
  • Tap convention: the series element sees Vf/NkV_f / N_kVf​/Nk​. The stored ANAREDE voltages confirm this: across fixed-tap, low-impedance transformers, Vt≈Vf/aV_t \approx V_f / aVt​≈Vf​/a in 96 % of cases, compared with Vf⋅aV_f\cdot aVf​⋅a.

The branch stamps used in YbusY_{bus}Ybus​ are:

Yff=yk+jbk/2ak2,Yft=−ykak e−jφk,Ytf=−ykak ejφk,Ytt=yk+jbk/2.\begin{aligned} Y_{ff} &= \frac{y_k + j b_k/2}{a_k^2}, & Y_{ft} &= -\frac{y_k}{a_k\,e^{-j\varphi_k}}, \\[2pt] Y_{tf} &= -\frac{y_k}{a_k\,e^{j\varphi_k}}, & Y_{tt} &= y_k + j b_k/2 . \end{aligned}Yff​Ytf​​=ak2​yk​+jbk​/2​,=−ak​ejφk​yk​​,​Yft​Ytt​​=−ak​e−jφk​yk​​,=yk​+jbk​/2.​

The branch terminal powers, flowing into the branch, are:

Sf=Vf (YffVf+YftVt)∗,St=Vt (YtfVf+YttVt)∗.S_f = V_f\,(Y_{ff}V_f + Y_{ft}V_t)^*,\qquad S_t = V_t\,(Y_{tf}V_f + Y_{tt}V_t)^* .Sf​=Vf​(Yff​Vf​+Yft​Vt​)∗,St​=Vt​(Ytf​Vf​+Ytt​Vt​)∗.

Admittance matrix

Section titled “Admittance matrix”

build_ybus assembles the sparse matrix by adding the four stamps of every branch, plus j bishj\,b^{sh}_ijbish​ on each diagonal for bus and line shunts. Bus injections follow:

Sicalc=Vi (∑jYijVj)∗,Picalc=Re⁡Sicalc,  Qicalc=Im⁡Sicalc.S_i^{calc} = V_i\,\big(\textstyle\sum_j Y_{ij} V_j\big)^* ,\qquad P_i^{calc} = \operatorname{Re} S_i^{calc},\; Q_i^{calc} = \operatorname{Im} S_i^{calc}.Sicalc​=Vi​(∑j​Yij​Vj​)∗,Picalc​=ReSicalc​,Qicalc​=ImSicalc​.

For solving, the branch matrix is frozen as a base matrix. Shunt changes and tap or phase changes are added on top as stamp differences:

Ybus=Ybase+diag⁡(j bsh)+∑k∈controlled(stamps(ak,φk)−stamps(ak0,φk0)).Y_{bus} = Y^{base} + \operatorname{diag}(j\,b^{sh}) + \sum_{k\in\text{controlled}} \big(\text{stamps}(a_k,\varphi_k) - \text{stamps}(a_k^0,\varphi_k^0)\big).Ybus​=Ybase+diag(jbsh)+k∈controlled∑​(stamps(ak​,φk​)−stamps(ak0​,φk0​)).

This makes the Newton step’s matrix update cheap on the reduced network. A branch with zero impedance cannot be stamped; it must be contracted first. See Network reduction.

Removed circuits

Section titled “Removed circuits”

A DLIN record is skipped when any of these conditions applies:

  • O ≠ "A";
  • E = "D";
  • Si = "D" or Sj = "D";
  • either terminal bus is out of service.

Transformer controls

Section titled “Transformer controls”

DLIN records with 0<Tmn<Tmx0 < T_{mn} < T_{mx}0<Tmn​<Tmx​ are on-load tap changers that regulate a bus voltage. DCTR records with PCtrl = P are phase shifters that regulate an active-power flow. Both are described in Tap and phase controls.
