Solution pipeline

Both solvers follow the same pipeline. Only the numerical core differs.

1. Parsing

Section titled “1. Parsing”

parse_dat_file reads each block header, such as param: DBAR: No Name Tb … :=. It then splits the tokens up to the terminating ; with shell-style quoting, so names like "ANGRA1UNE001" remain single tokens. Records become dictionaries keyed by column name. Repeated blocks are concatenated, and their columns must be identical.

2. Case assembly

Section titled “2. Case assembly”

build_power_flow_case turns records into model objects. Only records in service are used:

  • Records filtered out:
    • records whose operation flag O is not "A";
    • records whose state E is "D";
    • DLIN circuits with either terminal switch Si or Sj set to "D".
  • Bus types:
    • Tb = 0 is PQ;
    • Tb = 1 is PV;
    • Tb = 2 is the reference bus;
    • Tb = 3 is a PQ bus with voltage-limit control.

The component pages explain how each block contributes to the network and injections.

3. Network reduction

Section titled “3. Network reduction”

Very low-impedance links create ill-conditioned Jacobians, so they are contracted. These links include bus-section switches, bypassed series compensators, and ideal ties. Each island receives a reference bus. Transformer taps that contradict the stored operating point are corrected. See Network reduction.

4. Solve

Section titled “4. Solve”
  • Newton-Raphson solves the mismatch equations together with SVC, LTC, and phase-shifter control equations.
  • Optimization power flow minimizes bounded residuals in a nonlinear program.

Both methods then run outer control passes for discrete controls:

  • generator reactive limits;
  • switched shunt banks;
  • LCC converter set-points;
  • LTC activation in Newton;
  • SVC operating regions in the optimization model.

The solve repeats until no control changes.

5. Results

Section titled “5. Results”

The reduced solution is expanded back to every original bus as Vi=si Vrep(i)V_i = s_i\,V_{\text{rep}(i)}Vi​=si​Vrep(i)​. In this expression, sis_isi​ is the complex scale of the contraction. All solved control states are written back to the original devices:

  • transformer taps and phase shifts;
  • shunt steps;
  • SVC outputs;
  • LCC set-points;
  • bus types.

Reported injections therefore use the final settings. ExportSolution writes everything to an Excel workbook; see Exporting results.
