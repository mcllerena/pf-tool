## What is inside

<CardGrid>
  <Card title="Data file" icon="document">
    AMPL-style `param: BLOCK: columns :=` sections exported from ANAREDE `.pwf` cases. Every block
    and column used by the solver is documented.
  </Card>
  <Card title="Components" icon="puzzle">
    Buses, generators, lines, transformers with LTC and phase-shifter control, series compensators,
    shunt banks, SVCs, and HVDC LCC links.
  </Card>
  <Card title="Newton-Raphson" icon="rocket">
    Sparse polar Newton method. Its state includes SVC outputs, LTC taps, and phase-shift angles.
    Outer passes handle discrete controls.
  </Card>
  <Card title="Optimization power flow" icon="setting">
    A Pyomo nonlinear program solved with Ipopt. It uses signed residuals with per-bus and aggregate
    bounds and switches SVC operating regions between solves.
  </Card>
</CardGrid>

## Benchmark at a glance

All 11 cases in `tests/data/` converge with every method. For each run, the maximum absolute mismatch is below the case tolerance of $10^{-4}$ pu.

| Method                          | Converged | Mean time per case |
| ------------------------------- | --------: | -----------------: |
| Newton-Raphson                  |   11 / 11 |              2.8 s |
| Optimization, Newton warm start |   11 / 11 |             10.2 s |
| Optimization, cold start        |   11 / 11 |             37.6 s |

## Package layout

Install with `pip install pf-tool`, then import from `pf_tool`. The main classes are also exported at the top level: `from pf_tool import NewtonRaphsonPowerFlow, OptimizationPowerFlow, ExportSolution`.

| Path                        | Contents                                                                                                                              |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `pf_tool/newton_raphson.py` | `NewtonRaphsonPowerFlow` and the shared `PowerFlowResult` / `BusSolution` results                                                     |
| `pf_tool/optimization.py`   | `OptimizationPowerFlow`, the Pyomo model builder, and the SVC region logic                                                            |
| `pf_tool/exporter.py`       | `ExportSolution`: Excel workbook with one sheet per component                                                                         |
| `pf_tool/models/`           | One module per component: `bus`, `branch`, `transformer`, `csc`, `shunt`, `svc`, `hvdc_lcc`, `generator`, `case`, `network_reduction` |
| `pf_tool/utils/`            | `dat_parser` (block reader), `utils` (case assembly), `network` (Ybus and power calculations)                                         |

In the repository, the package lives under `src/`, the eleven `CASO*-FLOW.dat` cases under `tests/data/`, and minimal scripts that run each solver class under `examples/`.
